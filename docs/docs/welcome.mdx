<p style={{textAlign: 'center'}}>A Git-driven reconciler for Linux workloads.</p>

podcd is a GitOps tool to manage quadlets on a linux host.
Podman pods are managed by utilizing Quadlets and systemd (or Docker Compose projects).

There is no control plane beyond the agent on each host.

## Where to go next

- [Installation](installation.md) - install the binary.
- [Overview](overview.md) - how podcd works.
